Block Arduino

Snap blocks together. Click Upload. It runs on your Arduino.

A Scratch-style editor for Arduino with event scripts that run side by side, and a Smart Upload that finds your board and fixes common upload problems by itself.

macOS

macOS 11 or later. Pick Apple Silicon for M1–M4 Macs.

Not notarised yet: the first time, right-click the app and choose Open. If macOS says it is damaged, run xattr -cr "/Applications/Block Arduino.app".

Windows

Windows 10 or 11, 64-bit. The installer adds a Start menu shortcut.

Not code-signed yet: if SmartScreen appears, choose More info → Run anyway. Clone boards with a CH340 chip may need its USB driver.

Linux

64-bit Ubuntu, Debian, Fedora and others.

To upload, your user needs the serial port: sudo usermod -aG dialout $USER, then log out and in.

What's inside

Built from the Block Arduino design doc.

Events, not loopsHat blocks like "when button pressed" and "every 500 ms". Waits never freeze other scripts.
One-click Smart UploadFinds the port by USB ID, switches the Nano bootloader, follows Leonardo port hops and retries up to 4 times.
Real partsPins, switches, servos, steppers, NeoPixels (pin or I2C NeoDriver) and I2C LCDs with auto address.
Always see the C++Live code panel. Click a line to find its block; build errors point at the block that caused them.
Your own blocksInline C++ blocks plus a Block Maker for reusable custom blocks you can share.
Works offlinearduino-cli is bundled. Board support downloads once, then everything runs without internet.
· Built with Electron, Blockly and arduino-cli.
