Repair bootloader

    
Use this when a board never answers on any setting, or reports signature 0x000000. You need a second, working Arduino Uno as a programmer.

    
    
      
  1. Open the Arduino IDE on the helper Uno and upload File → Examples → 11.ArduinoISP → ArduinoISP.
    2. 
      
  2. Wire helper → broken board: D13→D13, D12→D12, D11→D11, D10→RESET, 5V→5V, GND→GND (on a Mega: D52, D50, D51, RESET).
    3. 
      
  3. Put a 10 µF capacitor between RESET and GND on the helper Uno (stripe to GND).
    4. 
      
  4. Pick the broken board type in the board menu, choose the helper's port below and click Burn.
    5. 
    

    
    

  

  
    
Block Arduino 

    
Program an Arduino by snapping blocks together, like Scratch, with one-click Smart Upload.

    

    
Built with Electron, Blockly and arduino-cli. Open source.
